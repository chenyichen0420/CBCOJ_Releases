## Basic Information

This is the latest internal test version of CBCOJ after undergoing significant restructuring over the past month. The restructuring involves architectural adjustments, feature enrichment, and interface updates, which is why the major version number has nearly doubled. However, this version is not yet stable, and numerous vulnerabilities have been discovered during the trial operation. Therefore, it will not be released as an official version. The next official release is expected to be available in at least one month.

**⚠️ Important Reminder: We strongly advise against deploying any previous versions locally—these versions have been confirmed to have severe security vulnerabilities that may pose risks to user data. Please ensure you experience the latest development version through the official website.**

## What’s the Issue?

Although the current test version introduces many new features, its stability is insufficient, and various potential vulnerabilities remain. We are working diligently to address these issues and plan to release a stable official version in at least one month.

In contrast, previous versions have severe security vulnerabilities (such as insecure network connections, data leakage risks, etc.) that cannot be completely fixed with simple patches. Therefore, we strongly recommend that users do not deploy or use any older versions. Always access the latest development version through the official website for better security and functionality.

Nevertheless, this restructuring marks an important milestone in CBCOJ's development, which is why a larger version number has been assigned to this release.

## How Can You Obtain Specific Information About This Version?

You can experience the online demo of the latest version on our [official website](cbcoj.dpdns.org). We will not provide a major version for specific feature releases.
